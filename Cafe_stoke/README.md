# 🏪 نظام إدارة مخزون الكافيه
## Cafe Stock Management System

نظام شامل لإدارة مخزون الكافيه مع ربط Google Sheets وماسح الباركود

---

## 📋 المميزات

✅ **إدارة المشاريع والمنتجات**
- ربط مباشر مع Google Sheets
- إضافة وتعديل المشاريع والمنتجات

✅ **إخراج وإدخال المخزون**
- تتبع حركة المخزون بدقة
- فلترة ذكية للمنتجات حسب المشروع
- دعم إضافة منتجات متعددة

✅ **ماسح الباركود**
- دعم كاميرا الموبايل والكمبيوتر
- يعمل على جميع المتصفحات الحديثة
- دعم أنواع باركود متعددة

✅ **تصميم متجاوب**
- يعمل على الموبايل والتابلت والكمبيوتر
- واجهة عربية RTL
- ألوان مريحة للعين

## 🚀 البدء السريع

### الخطوة 1: إنشاء جدول Google Sheets
1. افتح [Google Sheets](https://sheets.google.com)
2. أنشئ جدول جديد
3. أنشئ الشيتات: `Projects`, `Products`, `Settings`

### الخطوة 2: إعداد Google Apps Script
1. Extensions → Apps Script
2. انسخ كود `google-apps-script.js`
3. عدّل `SPREADSHEET_ID` بمعرف جدولك
4. Deploy → New deployment → Web app
5. انسخ رابط الـ Web App

### الخطوة 3: ربط النظام
1. افتح `0541.html`
2. الصق رابط Web App
3. احفظ واختبر الاتصال

### الخطوة 4: ابدأ الاستخدام!
- افتح `index_Cafe_stoke.html` للوصول للنظام

## 💡 نصائح الاستخدام

### للحصول على أفضل أداء:
1. استخدم متصفح Chrome أو Safari على الموبايل
2. امنح صلاحية الكاميرا عند طلبها
3. احفظ رابط Web App في مكان آمن
4. قم بعمل نسخة احتياطية من جدول Sheets

### عند التسليم لشخص آخر:
1. أعطه نسخة من ملفات المشروع
2. وجهه لقراءة `INSTALLATION_GUIDE.md`
3. تأكد من إنشائه لجدول Sheets جديد خاص به
4. تأكد من تعديله لـ `SPREADSHEET_ID` في الكود

## ⚠️ ملاحظات مهمة

1. **الأمان:**
   - لا تشارك رابط Web App مع أي شخص
   - لا تشارك معرف جدول Google Sheets
   - غيّر كلمة المرور الافتراضية

2. **الصلاحيات:**
   - تأكد من "Execute as: Me"
   - تأكد من "Who has access: Anyone"

3. **التحديثات:**
   - عند تعديل الكود، اعمل "New deployment"
   - لا تستخدم "Manage deployments"
