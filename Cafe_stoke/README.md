# نظام إدارة مخزون الكافيه (Cafe Stock)

## وصف المشروع
نظام ويب لإدارة مخزون الكافيه، يدعم إدخال وتصدير المنتجات، الربط مع Google Sheets، البحث بالباركود أو اسم المنتج، ويعمل كتطبيق PWA مع دعم العمل دون اتصال.

## المميزات
- إدخال وتصدير المنتجات للمخزون.
- البحث الذكي بالباركود أو اسم المنتج.
- ربط مباشر مع Google Sheets لتخزين البيانات.
- دعم الماسح الضوئي للباركود عبر الكاميرا.
- واجهة عربية حديثة وسهلة الاستخدام.
- شريط تحميل احترافي عند إرسال البيانات.
- دعم العمل دون اتصال (PWA + Service Worker).

## طريقة التشغيل
1. تأكد من وجود Node.js.
2. شغل السيرفر:
   ```
   node Cafe_stoke/server.js
   ```
3. افتح أحد الروابط التالية في المتصفح:
   - http://localhost:3000/index_Cafe_stoke.html
   - http://localhost:3000/Stock_In.html
   - http://localhost:3000/Stock_Out.html

## الإعدادات
- قم بتعديل ملف `config.json` لإضافة رابط Google Apps Script ومعرف Google Sheet.
- يمكنك ضبط الإعدادات من صفحة الإعدادات (0541.html).

## المجلدات والملفات المهمة
- `server.js` : سيرفر Node.js لتقديم الملفات والخدمات.
- `sw.js` : Service Worker لدعم العمل دون اتصال.
- `config.json` : إعدادات الربط مع Google Sheets.
- `Stock_In.html` : صفحة إدخال المنتجات.
- `Stock_Out.html` : صفحة تصدير المنتجات.
- `index_Cafe_stoke.html` : الصفحة الرئيسية.
